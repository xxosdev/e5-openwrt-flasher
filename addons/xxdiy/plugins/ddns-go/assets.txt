# ddns-go 后端 + 它的 LuCI 界面。两者都不在官方 25.12.5 源里，只能从 GitHub Release 拿。
#
# 为什么用 openwrt-24.10 那一份（里面是 ipk）而不是 SNAPSHOT 那一份（里面是 apk）：
#   * 我们解包铺文件，不经过 apk 的依赖解析、签名校验和 postinst，24.10 的 ipk
#     和 SNAPSHOT 的 apk 解出来的文件树是一样的；
#   * easytier 那边必须走解包（它声明了 kmod-tun，我们的内核把 TUN 编进去了、
#     根本没有这个包，apk add 会 unsatisfiable），同一套流水线用同一种机制更省心。
#
# 包内容（解出来铺进镜像的）：
#   ddns-go                /usr/bin/ddns-go、/etc/init.d/ddns-go、/etc/config/ddns-go
#   luci-app-ddns-go       /www/luci-static/resources/view/ddns-go/*.js
#                          /usr/share/luci/menu.d/luci-app-ddns-go.json
#                          /usr/share/rpcd/acl.d/luci-app-ddns-go.json
#                          /usr/share/rpcd/ucode/luci.ddns-go
#                          /usr/libexec/ddns-go-call
#                          /etc/uci-defaults/99-luci-ddns-go
#   luci-i18n-ddns-go-zh-cn 中文语言包
#
# 格式: <文件名> <URL> <字节数> <sha256> <ipk 前缀,逗号分隔>
# sha256 取自 GitHub API 的 asset digest，不是下载后自己算的。
